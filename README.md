# Oferta GuateGeeks

Sitio independiente para presentar los programas educativos de GuateGeeks a instituciones educativas.

## Estructura

- `index.html`: página principal y experiencia interactiva.
- `assets/`: fotografías, logotipo y recursos visuales.

## Uso local

Abrir `index.html` directamente en un navegador. No requiere dependencias ni proceso de compilación.

## Publicación

Esta carpeta está preparada para convertirse en el contenido raíz del repositorio `GuateGeeks/oferta_guategeeks`.
